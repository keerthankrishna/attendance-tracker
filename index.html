Students, attendance, summaries & payments — saved in Supabase, synced across your devices.

⚙️ Setup needed

This tracker is not connected to Supabase yet. The file config.js still contains placeholder values (PASTE_…).

To finish setup, follow SETUP.md:

1. In Supabase, run supabase.sql in the SQL Editor.
2. Create your login user under Authentication → Users, and disable public sign-ups.
3. Copy your Project URL and anon / publishable key (Settings → API) into config.js.
4. Upload the updated config.js to GitHub and reload this page.

Never put a service_role key or any password in config.js — only the Project URL and the anon key belong there.

Sign in

This tracker is private. Sign in with the account created for you in Supabase (Authentication → Users). There is no public sign-up.
